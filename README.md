# ماخولا — Makhoola

وب‌سایت گروه موسیقی **ماخولا**؛ رشت، از ۱۳۹۲.

نشانی: **https://bahramgg.github.io/Makhoola/**

## ایده: پیکره‌ی رود

نام گروه از شعر «ماخ اولا»ی نیما یوشیج می‌آید: «پیکره‌ی رود بلند / می‌رود نامعلوم». سایت هم یک رود است. صفحه‌ای که پایین برود ندارد.

کل سایت یک بدنه‌ی زنده است: تا نوزده هزار ذره‌ی جوهری روی زمینه‌ی سیاه (روی موبایل هشت هزار). با چرخاندن ماوس، کشیدن انگشت یا کلیدهای جهت، پایین‌دستِ رود می‌روید و ذره‌ها از یک فرم به فرم بعدی می‌ریزند، از راست به چپ، مثل خواندن فارسی. فرم‌ها این‌ها هستند:

| فرم | آنچه می‌شود |
|---|---|
| حلقه | ورود؛ با صدا یا بی‌صدا |
| نشان قلمدار | ۱۱ حرف دور نشان را می‌شود نواخت: هر حرف یک نت از دستگاه شور است. نُه حرف با کلیک دری‌اند به نُه فصل. |
| ماه | آلبوم دوم، «نمی‌کاهم»، که کمتر از یک ماه دیگر منتشر می‌شود. ذره‌ها ماه می‌شوند و ماه پنجره‌ای می‌شود به تیزر آلبوم. با کلیک روی ماه، تیزر با صدا پخش می‌شود. |
| آثار | نُه اثر، از تازه به قدیم. هر جلد اول از ذره‌ها ساخته می‌شود و بعد تصویر واقعی‌اش دانه‌دانه پیدا می‌شود. سال انتشار درشت و توخالی پشت جلد است. |
| خروس | میان همان آثار: نخستین آلبوم، با کلمه‌ی سرخ پوستری و ۹ قطعه. روی خروس بزنید تا بخواند. |
| رود | شعر نیما با نستعلیق روی جریان‌ها می‌رود. |
| از سنگ به سنگ | ۳۳ اجرا، سنگ‌هایی روی مسیر رود. پوستر هر اجرا روی دیوار پشت رود می‌چسبد. |
| چهره‌ها | چهار عضو گروه، از نقطه. |
| صحنه | ۱۶ عکس اجرا در تاریکی. نورافکن دست شماست. |
| پرده | ویدیوها. |
| دهانه | رود به دریا می‌رسد: تلگرام، پلتفرم‌ها، رزرو اجرا و کیت رسانه. |

جزئیات دیگر:

- **صدا:** سه‌تار با روش کارپلاس‌استرانگ ساخته می‌شود و صدای رود و باران از نویز. هیچ فایل صوتی بارگذاری نمی‌شود.
- **ساعت:** ساعت رشت به تقویم شمسی، و اگر بیننده جای دیگری باشد، ساعت خودش.
- **محافظ صفحه:** بعد از ۴۵ ثانیه بی‌حرکتی، نشان مثل لوگوی دی‌وی‌دی دور صفحه می‌چرخد.
- **نسخه‌ی متنی:** همه‌ی اطلاعات، ساده و بی‌جلوه. اگر مرورگر WebGL یا جاوااسکریپت نداشته باشد، همین نسخه نمایش داده می‌شود.

## ساختار

```
index.html              همه‌ی متن‌ها، نسخه‌ی متنی و داده‌های فرم‌ها (در <script id="mk-data">)
assets/css/style.css    طراحی؛ رنگ‌ها در :root
assets/js/river.js      موتور ذره‌ها (WebGL)
assets/js/forms.js      فرم‌ها: نشان، ماه، جلد، رود، مسیر اجراها، غبار، پرده، دریا، دی‌وی‌دی
assets/js/sound.js      سه‌تار نشان و صدای رود (Web Audio)
assets/js/app.js        حرکت در رود، فصل‌ها، فهرست، ساعت، تعامل‌ها
assets/fonts/           لاله‌زار، وزیرمتن، نوتو نستعلیق، IBM Plex Mono
assets/img/             نشان، جلدها، خروس، چهره‌ها، پوسترها (‎-sm‎ کوچک)، عکس‌ها، تصویر ویدیوها
assets/video/           تیزر «نمی‌کاهم»: نسخه‌ی کامل با صدا، و نسخه‌ی مربعِ بی‌صدا برای ماه (MP4 و WebM)
assets/press/           کیت رسانه
```

هیچ فونت، کتابخانه، تصویر یا ویدیویی از سرویس بیرونی بارگذاری نمی‌شود، جز ویدیوهای یوتیوب بخش «پرده»، آن هم بعد از کلیک.

## ویرایش محتوا

`index.html` از روی داده‌ها ساخته شده است. برای تغییر کوچک، می‌شود متن را مستقیم در `index.html` عوض کرد. دو جا را باید با هم عوض کنید:

- پنل فصل: `<section class="panel" data-step="…">`
- نسخه‌ی متنی: `<main id="archive">`

اجرای تازه را هم به فهرست `shows` در `mk-data` اضافه کنید و هم یک دکمه‌ی `stone` به `ol.stones`. پوستر را در `assets/img/shows/` بگذارید، یک نسخه‌ی کوچک با پسوند ‎-sm‎.

## انتشار

شاخه‌ی `gh-pages` روی GitHub Pages منتشر می‌شود. اگر دامنه عوض شد، آدرس‌های `canonical`، `og:url` و `og:image` را در `index.html` هم عوض کنید.
