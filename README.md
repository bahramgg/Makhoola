# ماخولا — Makhoola

وب‌سایت گروه موسیقی **ماخولا**؛ رشت، از ۱۳۹۲.

> «ماخ اولا» پیکره‌ی رود بلند / می‌رود نامعلوم / می‌خروشد هر دم / می‌جهاند تن، از سنگ به سنگ — نیما یوشیج

## ایده: سیاه‌مشق

سایت یک صفحه‌ی بلند و پیوسته است، مثل برگه‌ای که رویش مشق شده. منو، هدر و جعبه‌بندی معمول سایت‌ها را ندارد.

- **رنگ‌ها از خود لوگو:** کاغذ سفید و مرکب سیاه، مثل نشان قلمدار. شنگرف (قرمز) فقط برای مهرها و سرلوح‌هاست: رنگ تاج خروس و مهرهای «تمدید شد» روی پوسترها.
- **سرلوح‌ها:** هر بخش با یک کلمه‌ی بزرگ نستعلیق قرمز شروع می‌شود (رود، خروس، صداها، دیوار، چهره‌ها، نامه)؛ مثل رُبریک نسخه‌های خطی.
- **فهرست:** در حاشیه‌ی صفحه‌ی اول، کج نوشته شده، مثل حاشیه‌نویسی. بعد از اسکرول، یک مهر قرمز کوچک گوشه‌ی صفحه فهرست را باز می‌کند.

## اجرا روی سیستم خودتان

```bash
python3 -m http.server 8000
# سپس: http://localhost:8000
```

برای بارگذاری درست فونت‌ها و تصاویر، فایل را از طریق سرور باز کنید نه مستقیم.

## ساختار

```
index.html              همه‌ی محتوا
assets/css/style.css    طراحی (رنگ‌ها در :root)
assets/js/main.js       تعامل‌ها: قلم، نشان، رود، دیوار، هافتون، نمایشگر
assets/fonts/           نوتو نستعلیق، وزیرمتن، لاله‌زار (روی خود سایت)
assets/img/ink/         خروس (استخراج‌شده از پوستر قلمدار) و بافت کاغذ
assets/img/faces/       نقشه‌ی مرکب پرتره‌ها برای چاپ هافتون
assets/img/posters/     پوسترهای اجراها (‎-sm‎ نسخه‌ی کوچک است)
assets/img/covers/      جلد آلبوم و تک‌آهنگ‌ها
assets/img/video/       تصویر ویدیوها
assets/img/brand/       لوگوی وکتور، تصویر اشتراک‌گذاری og.jpg
```

هیچ فونت، کتابخانه یا تصویری از سرویس بیرونی بارگذاری نمی‌شود، تا سایت در ایران هم سریع باز شود. ویدیوهای یوتیوب فقط وقتی کسی روی آن‌ها بزند بارگذاری می‌شوند.

## ویرایش محتوا

- **پوستر اجرای تازه:** در بخش `id="divar"` یک `<figure class="poster">` را کپی کنید. پوستر را در `assets/img/posters/` بگذارید (نسخه‌ی کوچک حدود ۴۲۰ پیکسل با پسوند ‎-sm‎) و نسبت عرض به ارتفاع را در `data-ar` بنویسید. مهر روی پوستر: `<span class="stamp">تمدید شد</span>`. چیدمان دیوار خودکار است.
- **تک‌آهنگ تازه:** یک `<article class="painting">` در بخش `id="sedaha"` اضافه کنید. جای آن روی دیوار با `--x`، `--y` (برحسب vw)، `--w` (عرض) و `--r` (چرخش) تعیین می‌شود.
- **متن رود:** خط‌های `<p class="rl">` در بخش `id="rud"`. اندازه، دامنه‌ی موج و سرعت هر خط با `data-*` تنظیم می‌شود.
- **رنگ‌ها:** متغیرهای `:root` در ابتدای `style.css`.

## انتشار

نشانی سایت روی GitHub Pages: **https://bahramgg.github.io/Makhoola/**

- شاخه‌ی منتشرشده `gh-pages` است؛ هر تغییری که روی این شاخه push شود، چند دقیقه بعد روی سایت می‌آید.
- GitHub Pages یک بار باید در تنظیمات مخزن روشن شود: Settings → Pages → Deploy from a branch → `gh-pages` / `(root)`.
- فایل `.nojekyll` جلوی پردازش Jekyll را می‌گیرد.
- اگر سایت را به دامنه‌ی دیگری بردید، آدرس‌های `canonical`، `og:url` و `og:image` را در `index.html` عوض کنید.
