# ماخولا — Makhoola

وب‌سایت گروه موسیقی **ماخولا**؛ راک آلترناتیو از رشت، از ۱۳۹۲.

> «ماخ اولا» پیکره‌ی رود بلند / می‌رود نامعلوم / می‌خروشد هر دم / می‌جهاند تن، از سنگ به سنگ — نیما یوشیج

سایتی ایستا (HTML/CSS/JS خالص، بدون فریم‌ورک و بدون مرحله‌ی build) با فضای بصری برگرفته از لوگو و پوسترهای گروه:
شب جوهری، قرمز تاج خروس، کهربای نور صحنه، کاغذ کرافت، بافت هافتون و مهرهای «تمدید شد / SOLD OUT».

## بخش‌ها

| بخش | توضیح |
|---|---|
| Hero | نشان ماخولا (وکتورشده از لوگوی قلمدار) با انیمیشن «لرزش خط» و شعله‌ور شدن، نوار خبر |
| نمی‌کاهم | آلبوم تازه (به‌زودی — پاییز ۱۴۰۵) |
| ماخ‌اولا | داستان گروه، شعر نیما به خط نستعلیق، شاعران، نقاط عطف |
| گروه | پرتره‌های هافتون (چاپ سیلک) اعضا + همراهان |
| آثار | آلبوم «خروس» با فهرست قطعه‌ها و شناسنامه + قفسه‌ی تک‌آهنگ‌ها |
| ویدیو | ویدیوهای یوتیوب (فقط با کلیک بارگذاری می‌شوند) |
| اجراها | «از سنگ به سنگ»: آرشیو ۳۱ اجرا از ۱۳۹۵ تا ۱۴۰۵ روی رودی که با اسکرول کشیده می‌شود، با فیلتر شهر |
| عکس‌ها | نوار فیلم (کنتاکت‌شیت) از عکس‌های اجراها |
| تماس | پلتفرم‌های شنیدن، شبکه‌ها، رزرو اجرا |

## اجرا روی سیستم خودتان

```bash
python3 -m http.server 8000
# سپس: http://localhost:8000
```

(هر وب‌سرور ایستای دیگری هم کار می‌کند. برای بارگذاری درست فونت‌ها، فایل را از طریق سرور باز کنید نه مستقیم.)

## ساختار

```
index.html              همه‌ی محتوا
assets/css/style.css    طراحی (توکن‌های رنگ در :root)
assets/js/main.js       تعامل‌ها (هدر، منو، رود اجراها، فیلتر، لایت‌باکس، ویدیو)
assets/fonts/           فونت‌ها روی خود سایت: لاله‌زار، وزیرمتن، نوتو نستعلیق، Bebas Neue
assets/img/brand/       لوگوی وکتور (emblem*.svg)، تصویر اشتراک‌گذاری og.jpg، بافت کاغذ
assets/img/posters/     پوسترهای اجراها (هر کدام نسخه‌ی کوچک ‎-sm‎ و بزرگ)
assets/img/live/        عکس‌های اجرا
assets/img/covers/      جلد آلبوم و تک‌آهنگ‌ها
assets/img/members/     پرتره‌ها (‎-dots‎ ماسک هافتون است)
```

همه‌ی فونت‌ها و تصاویر روی خود سایت‌اند و هیچ وابستگی به گوگل‌فونت یا CDN ندارند، تا در ایران هم سریع و بی‌دردسر باز شود.

## ویرایش محتوا

- **اجرای تازه:** در `index.html` بخش `id="live"`، یک `<article class="show">` را کپی کنید. شهر را در `data-city` (`rasht` / `tehran` / `shiraz`) بنویسید، پوستر را در `assets/img/posters/` بگذارید (نسخه‌ی کوچک حدود ۴۲۰ پیکسل با پسوند ‎-sm‎). برای مهر روی پوستر: `<span class="stamp">تمدید شد</span>`. عددهای دکمه‌های فیلتر را هم به‌روز کنید.
- **تک‌آهنگ تازه:** یک `<li class="single">` در `id="shelf"` اضافه کنید.
- **نوار خبر بالای صفحه:** متن‌های `.ticker__item` (هر دو گروه را یکسان نگه دارید).
- **رنگ‌ها:** متغیرهای `:root` در ابتدای `style.css`.

## انتشار

سایت کاملاً ایستاست و روی GitHub Pages، Netlify، Cloudflare Pages یا هر هاست معمولی بالا می‌آید.
بعد از انتشار، در `index.html` آدرس `og:image` را به آدرس کامل تبدیل کنید (مثلاً `https://example.com/assets/img/brand/og.jpg`) تا پیش‌نمایش لینک در تلگرام و شبکه‌ها درست نمایش داده شود.
