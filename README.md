# ماخولا — Makhoola

وب‌سایت گروه موسیقی **ماخولا**؛ رشت، از ۱۳۹۲.

نشانی: **https://bahramgg.github.io/Makhoola/**

## آنچه سایت دارد

ساختار سایت مثل سایت گروه‌های راک جهانی است. فقط آنچه امروز به کار شنونده و برگزارکننده می‌آید در سایت هست:

| بخش | محتوا |
|---|---|
| آلبوم تازه | «نمی‌کاهم»، آلبوم دوم. زمینه‌ی صفحه بخشی از تیزر است و دکمه‌ی «تیزر آلبوم» نسخه‌ی کامل را با صدا پخش می‌کند. خبر پیش‌فروش در تلگرام اعلام می‌شود. |
| تازه‌ترین تک‌آهنگ | «می‌کشانی‌ام» (ضبط‌شده برای آلبوم تازه) با لینک اسپاتیفای، اپل موزیک و ساندکلاد، و اجرای زنده‌ی «آیا صبح» از آلبوم «نمی‌کاهم». |
| موسیقی | همه‌ی آثار با لینک شنیدن، و همه‌ی پلتفرم‌های ماخولا. |
| اجرا | فقط اجراهای پیش رو. فعلاً اجرای تازه‌ای اعلام نشده. دکمه‌ی «خبرم کن» به تلگرام می‌رود و دکمه‌ی دیگر رزرو اجرا برای برگزارکنندگان است. |
| ویدیو | تازه‌ترین ویدیو و سه ویدیوی دیگر، که در خود صفحه پخش می‌شوند. |
| فروشگاه | پیش‌فروش «نمی‌کاهم» (به‌زودی) و نسخه‌ی دیجیتال «خروس» در بیپ‌تونز. |
| درباره | معرفی کوتاه و اعضای گروه. |
| خبرها | عضویت در کانال تلگرام و شبکه‌های دیگر. |
| تماس | شماره‌ی رزرو، اینستاگرام و فایل‌های پرس‌کیت. |

## طراحی

پس‌زمینه سیاه است. عکس‌ها دوتونِ سرمه‌ای و کرم‌اند، مثل پوسترهای تازه‌ی گروه. مه روی تیزر حرکت می‌کند و تیترها فارسی و درشت‌اند. شعر نیما و فروغ با نستعلیق آمده است.

## ساختار

سایت ایستا است: HTML و CSS و جاوااسکریپت ساده، بدون کتابخانه و CDN. فونت‌ها روی همین سایت میزبانی می‌شوند: وزیرمتن، نستعلیق و IBM Plex Mono.
